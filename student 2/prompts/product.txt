Write ONE Node.js program for Node 18, to be saved as product.js.
Use only built-in modules (http, fs, os). No npm packages, no Express. Use http.createServer.
Listen on 0.0.0.0, port 3001. Accept an optional port number as the first command-line argument (process.argv[2]).
Never crash on a bad request.

Rules for EVERY response:
- The body is JSON, with header Content-Type: application/json.
- Add these headers to every response:
    Access-Control-Allow-Origin: *
    Access-Control-Allow-Methods: GET, POST, DELETE, OPTIONS
    Access-Control-Allow-Headers: Content-Type
- Any OPTIONS request (any path) answers 204 with those same headers.
- GET /health answers 200 with {"service": "product", "status": "ok"} and does no simulated work.
- Print ONE line per request in the terminal: time, method, path, status.
- A bad request (for example invalid JSON) answers 400 with {"error": "..."}.

What this service does (name: product):

GET /products
  -> 200 {"products": [ {"id": "p1", "name": "USB-C cable 1 m", "price": 9.9}, ... ]}
  At least 3 products. id and name are strings, price is a number greater than 0.
GET /products/<id>
  -> 200 with that one product object, or 404 {"error": "product not found"}.
Any other path -> 404 {"error": "not found"}.

Simulated CPU work: for every request EXCEPT /health and OPTIONS, call burn(10) before building the answer. Use exactly this function:

function burn(ms) {
  const end = process.hrtime.bigint() + BigInt(Math.round(ms * 1e6));
  while (process.hrtime.bigint() < end) { /* busy */ }
}

Return only the complete code of product.js, no explanations.
